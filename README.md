DiGi — Digital Agency Landing Page

  A professional, responsive multi-section landing page for a digital agency. This project was developed based on a precise Figma design to demonstrate advanced HTML5, CSS3 techniques, and    cross-browser stability.
link: https://koskovtsev.github.io/di-gi/

Features & Technical Highlights
  Pixel-Perfect Approach: Developed strictly following a Figma mockup, maintaining layout consistency and typography.
  Fully Responsive: Implemented a mobile-first/fluid approach ensuring a seamless experience from 320px to 1920px.
  Interactive Components:
  Custom Navigation: Smooth anchor navigation and a CSS-only mobile menu toggle.
  Sliders: Integrated and customized Owl Carousel for dynamic content display (Intro and Testimonials).
  Masonry-style Portfolio: A structured gallery section with custom hover effects and SVG iconography.
  SEO & Social Optimization: * Semantic HTML5 tags for better accessibility and search indexing.
  Open Graph (OG) and Twitter Card meta tags implemented for rich social media sharing.
  Performance & Assets: * Optimized SVG symbols for icons to reduce HTTP requests.
  Customized Google Fonts integration for unique branding.
Tech Stack
  HTML5: Semantic markup, SVG sprites.
  CSS3: Flexbox, Positioning, Transitions, and standard layout practices.
  JavaScript: jQuery (dependency for Owl Carousel) and custom logic for interactive elements.
  Tools: Figma (UI/UX design source), Git/GitHub, Chrome DevTools.
